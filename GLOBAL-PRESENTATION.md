# Worldwide observation presentation

The global layer reads a durable, immutable published snapshot. All manifest,
tile, popup, detail and export routes are local reads; none starts acquisition.
The designated ingestion owner is configured separately. The original bounded
AOI and Area Analytics paths reuse matching global source/day partitions before
using a separately governed regional fallback. Missing platform/day jobs alone
are acquired. A retained current UTC day's partial reporting is labeled partial.

## Bounded presentation protocol

`GET /global/manifest?window=24h|48h|7d` returns a stable snapshot ID, the exact
UTC start and exclusive end, source/partition generations, status, retrieval and
latest acquisition, counts, display extent and tile template. The browser uses
the published anchor; camera requests never create their own time windows.

`GET /global/tiles/{snapshot}/{window}/{z}/{x}/{y}.json` returns gzip-capable,
versioned GeoJSON. This is a bounded spatial protocol, not an MVT claim. It is
implemented with existing MapLibre GeoJSON support and SQLite rather than a new
distributed tile stack. Its limits and fixture measurements are explicit below.
URLs are immutable and cacheable for one year with encoding-aware ETags. The
manifest has a separate 30-second cache policy. No random cache-busting timestamps
are appended. Server tile caches are bounded to 256 entries/32 MiB, and fixed
striped build locks coalesce simultaneous identical generation work.

At zoom `z`, aggregates occupy a single global Web Mercator hierarchy at level
`z+4`, or 16×16 cells per requested tile. Every center has exactly one cell owner;
tile edges do not run separate clustering. At zoom 12 and above, a tile with at
most 1,024 observations serves individual records. Denser tiles retain exact
hierarchical aggregates instead of dropping or sampling records. Every response
has at most 1,024 features. Counts represent satellite records. Aggregate color
is maximum valid reported FRP: <10 MW yellow `#f5c518`, 10–<50 orange `#f97316`,
≥50 red `#dc2626`; a group without valid FRP uses the unknown color.

The index stores original coordinates and normalized Mercator positions once.
SQLite RTree bounds narrow regional requests; exact normalized cell intervals
resolve seams. Longitude +180 belongs to the same wrapped column as −180 while
stable IDs retain the original canonical coordinates. Wrapped rendered copies
must be deduplicated by ID by the client. Polar records beyond ±85.05112878°
remain in canonical inspection, counts and exports, and the manifest reports
their count. The current square tile display does not render those polar
records; they are never represented as a measured zero.

## Frozen inspection and complete exports

`POST /global/observations` accepts:

```json
{
  "snapshotId": "published snapshot identity",
  "window": "24h",
  "aggregateId": "tile-provided hierarchy identity",
  "options": { "page": 1, "pageSize": 10, "search": "", "sort": "newest", "groupBy": "none" }
}
```

The aggregate encodes snapshot, interval, hierarchy cell and initial display
filters. Camera changes do not alter membership. Temporary native filters,
search, stable global sorting and grouping operate in SQLite before pagination.
Hour groups include their UTC date. Unknown FRP, day/night and native confidence
remain unknown. `observationId` can select one canonical record. Page sizes are
1–100; the popup defaults to 10 and offers 25. An expired/pruned snapshot returns
an explicit unavailable response; it never substitutes the latest snapshot.

`POST /global/observations/export` accepts the same body plus `format` (`csv`,
`geojson`, `json`). Exports stream every matching record with no presentation or
pagination cap. CSV includes native metadata, exact interval, filters, selection
identity, matching count and source generation. GeoJSON and reproducibility JSON
also contain partition generations, source state and publication metadata.

## Measured behavior and limits

`tools/benchmark-global-results.json` is regenerated by the backend test suite.
It records cold/warm worldwide 24h and 7d tile generation, regional zoom,
aggregate inspection, bytes before/after gzip and Python allocation peak for a
15,000-record synthetic fixture. These are local CPU/database measurements with
memory tracing, not NASA throughput, production validation, browser memory or
navigation frame-rate measurements. The HTTP concurrency regression exercises
100 visitors against one frozen tile without any upstream work. Further tests
cover seam ownership, world wrap, poles, dense tile bounds, filter/count equality,
restart retention, snapshot freezing, revision replacement, exact AOI filtering,
missing-source supplements and the original Area Analytics stream.

Live acquisition transactions, source latency, deployed browser memory and frame
times remain deployment measurements. The first installation has no bundled live
dataset: it shows an explicit unavailable/building state until the owner publishes
its first successful extraction. Later restarts immediately reuse the last good
snapshot. No claim of the most efficient presentation is made from fixtures.
