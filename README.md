# Ethereal Explorer

SHARP's regional historical import, harmonized calendars, recurrence and
offline experimental outlook setup are documented in
[Historical analysis](HISTORICAL-ANALYSIS.md). Backend acquisition setup is in
[the backend README](src/backend_api/README.md).

Shared worldwide hotspots, durable ingestion, transaction settings and deployment
commands are documented in [Global hotspots](GLOBAL-HOTSPOTS.md). On Windows,
`./tools/start-global-backend.ps1` starts the backend with persistent global storage
and its shared ingestion owner enabled. No MAP_KEY is needed for public NRT bulk data.
