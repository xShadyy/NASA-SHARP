# Fira Sans fonts

These original WOFF2 assets were downloaded without modification from the official Google Fonts service. The interface uses only the Latin subset of Fira Sans Regular (400), Bold (700), and Black (900).

Google Fonts stylesheet:
https://fonts.googleapis.com/css2?family=Fira+Sans:wght@400;700;900&display=swap

Downloaded 2026-10-19 with a modern Chrome User-Agent. Each weight is a separate static font asset.

## Original files

- `fira-sans-latin-400.woff2`: https://fonts.gstatic.com/s/firasans/v18/va9E4kDNxMZdWfMOD5Vvl4jL.woff2
- `fira-sans-latin-700.woff2`: https://fonts.gstatic.com/s/firasans/v18/va9B4kDNxMZdWfMOD5VnLK3eRhf6.woff2
